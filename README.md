# Screen-Helfer

Windows-App: Mit **Win + Alt + Shift** einen Bildschirmbereich auswaehlen, Google Gemini zeigt die Loesung.

**Download:** unter [Releases](../../releases/latest) die Datei `Screen-Helfer-Setup.exe` herunterladen und starten.

Du brauchst einen eigenen, kostenlosen Gemini API-Key von https://aistudio.google.com/apikey .
Screenshots werden nicht gespeichert, nur an Google Gemini geschickt.
